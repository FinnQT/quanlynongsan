Xuất / Nhập Excel

⬇️ Xuất bảng kê 02/TNDN

Chỉ xuất/in các giao dịch còn dùng trong khoảng ngày đã chọn. Khi xuất file .xlsx sẽ có thêm các sheet DU_LIEU, BAN_HANG, CHI_PHI, KHACH_HANG để sao lưu và nhập lại.

⬆️ Nhập từ file Excel

Chọn file có sheet DU_LIEU (file mẫu hoặc file đã xuất). Cột Mã có thể để trống: hệ thống tự tạo mã theo ngày. Dòng đã có mã hoặc trùng nội dung sẽ bị bỏ qua, không ghi đè dữ liệu.
